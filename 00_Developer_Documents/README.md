# Developer documents

Canonical home for governance, agent operating docs, product/ops documentation,
policies, approvals, and research for LocalFirst Dating (Swipe Dating).

## Layout

| Path | Contents |
|---|---|
| `MISSION.md` | Mission, constraints, non-goals |
| `AGENTS.md` | Agent operating rules |
| `CLAUDE.md` | Claude Code entry |
| `CONTRIBUTING.md` | Contributor rules |
| `SECURITY.md` | Security contact / reporting |
| `docs/` | Architecture, governance, product, ops, specs |
| `policies/` | Community and policy drafts |
| `approvals/` | Authentic release approvals only |
| `Research/` | Research briefs and ethics notes |
| `GPT_Workspace_Documents/` | Workspace / R&D scratch (when present) |

Root-level names (`MISSION.md`, `docs/`, …) are symlinks into this directory so
existing scripts and CI paths keep working.
