## Implementation summary
- iPhone 14+ encodes and hardware-decodes HEIC. That is the store and iOS display path.
- Expo picker uses `Current` and no `quality` (those options were transcoding to JPEG).
- Upload sends the original pick. Server still rasterizes to 1080×2400, strips EXIF/GPS, and stores 8-bit HEIC 4:2:0.
- iOS fetches send `Accept: image/heic`. AVIF remains the web/Android display fallback.
